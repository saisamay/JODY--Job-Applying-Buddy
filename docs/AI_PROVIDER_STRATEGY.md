# AI routing under a zero-spend policy

The existing career service selects a provider through `configured()`; task inference goes through the per-user usage and encrypted cache layer. Ollama and deterministic fixtures are implemented. The locked preview uses the fixture provider for demonstration. A fixture comparison is not a production hiring or dispatch decision. The MCP bridge already exposes owner-scoped read and proposal tools. A model or MCP caller cannot grant consent, switch identity, approve applications, authorize email or alter limits.

## Capability and quota discovery

Save model revision, supported methods and modalities, effective limits, tier, observation time and source. Recheck at startup, on model retirement and periodically. ## Route by task

| Task | Preferred data path | Safe fallback |
|---|---|---|
| Text extraction | Parse text, PDF and DOCX locally. Classify ambiguous clauses with optional local model. | Consented text-only hosted model; queue missing evidence for review. |
| Vision | Local OCR, then an explicitly capable vision model for permitted images. | Ask for a text copy. Never send an unredacted resume screenshot by default. |
| Semantic matching | Deterministic hard filters, then local embeddings and reviewed evidence. Benchmark a small sentence-transformer with labeled retrieval examples on this host before enabling it. | Existing tested local embedding adapter. Store encoder ID, revision and dimensionality; rebuild a separate index on change. |
| Resume tailoring | Ground each candidate claim in authorized immutable evidence. Use a model for proposed wording, with diff, claim checks and versioned artifacts. | Owner review for missing evidence. Never invent metrics, employers or dates. |
| Email generation | Generate an unsent draft using minimum necessary facts. | Template or owner review. Approval covers recipient, final bytes and attachments. |
| Email classification | Process relevant thread fragments locally where possible; redact quoted chains and addresses. | Separately consented text route or unclassified dashboard event. No mailbox mutation from model output. |

For each future hosted call resolve user → credential → allowed task and data classes → provider/model/region consent → redacted payload → free quotas. Strip names, address, contact details, tokens, repositories and identifiers unless required and expressly allowed. Never include raw secrets in logs, prompts, cache keys or MCP results. Encrypt BYOK per tenant; another user's key, operator preflight key or a different provider is never an implicit fallback. Withdrawal blocks queued calls and invalidates prior authorization.

Deduplication, deadlines, location and salary filters, state transitions, ATS structural checks, spend admission and dispatch policy remain deterministic. Reserve per-user/provider/day budget transactionally before requests, honor the more restrictive account-wide cap, and count retries. On 429 apply Retry-After or bounded exponential backoff with jitter (at most two retries in the proposed policy); persist the next due time. Use an independently authorized free fallback only when privacy and capability agree. Otherwise defer or show a question. On 401/403 suspend that credential; on unknown pricing or billed-only capacity refuse admission. [Owner checks](SECRETS_CHECKLIST.md#4-optional-providers)
